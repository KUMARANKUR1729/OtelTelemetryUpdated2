# SigNoz stack (vendored from the load-testing repo)

Copied from `sel-load-testing/signoz-foundry/pours/deployment/` (generated by `foundryctl` from `casting.yaml`: compose, docker).
Only one change: the ingester's host ports are `14317`/`14318` (were `4317`/`4318`) so they do not clash with the POC collector.

```bash
docker compose -f signoz/compose.yaml up -d      # first start takes a few minutes (schema migration)
# SigNoz UI: http://localhost:8090 (create the admin account on first visit)
```
It creates the Docker network `signoz-network`; the POC collector and Grafana join it (see `docker-compose.signoz.yaml`).
ClickHouse is not published to the host: Grafana reaches it by container name inside that network.
